# Pipeline review bundle

## Current extraction path

`gzip -dc -> scripts/prefilter.c (compiled as scripts/prefilter) -> scripts/03_process_stream.py -> staging -> promotion`

Entry point: `scripts/run_source_extraction.sh`. Runtime configuration: `selected_candidates.json` (six configured cases; `--case-id case_002` selects one in Python). Native prefilter still covers all six windows. No additional real cases were extracted for this upload.

Requirements: Linux (`/proc`, `/dev/full`), Python 3 standard library, Bash, gzip, C compiler. Historical tests additionally use mawk and engineering memory tests use `/usr/bin/time`.

Build if needed:

```sh
cc -std=c11 -O2 -Wall -Wextra -Werror scripts/prefilter.c -o scripts/prefilter
```

The isolated test harnesses compile their own temporary copies; do not need to run extraction or supply the LANL archives to run tests.

## Existing tests and fixtures

```sh
python3 -m unittest discover -s tests/phase1 -p 'test_*.py' -v
python3 tests/phase1/run_existing_isolated.py
```

Fixtures are embedded/generated by the existing test code, not separate pre-existing fixture CSVs. See `record()`, `runner()` and the source fixture dictionary in `tests/phase1/test_unified_path.py`, `row()`/`fixture()` in `tests/test_all_sources.py`, and `row()` in `tests/test_auth_prefilter.py`.

Normal tiny fixtures cover AUTH/PROC/DNS/FLOWS. Deliberate larger synthetic inputs test chunk boundaries, the 1 MiB native record limit and oversized newline-free input. These are engineering fixtures, not fabricated forensic evidence or experimental case conditions. No full raw archives are used.

Run the old top-level tests via `run_existing_isolated.py`, not directly in a production workspace: some tests use default destination paths.

## Legacy dependencies — NOT the recommended production path

The isolated historical suite requires `run_auth_prefilter.sh`, `03_prefilter_auth.c`, `03_prefilter_auth.awk`, and `03_process_auth_stream.py`. Included verbatim only for reproducibility. Legacy code assumes early cutoff and includes an unbounded `getline()` reader. Do not use it for large real archives. Passing legacy behavior tests is not a safety certification. The historical shell comment claiming low RSS is not a current independently verified guarantee.

## Important current limitations

- The native parser implements minimal unquoted record validation, not general CSV parsing. Python provides additional CSV validation.
- Native record size cap is 1 MiB excluding LF; Python field limits can be stricter.
- Malformed records are counted/skipped under the existing policy, not universally fatal.
- No timestamp early stop in the current unified path; complete input EOF is required.
- Promotion is per-file atomic with ordinary-error rollback, not a crash-atomic multi-file transaction.
- Runner cleanup normally removes its temporary staging directory on exit; retention after an interrupted historical run is not a guarantee of durable failure staging.
- Correlation predicates are OR-based user/host matches within windows, not causal or attack-attribution rules.
